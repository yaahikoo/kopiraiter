# Копирайтер

Небольшое приложение для Windows, которое вводит заранее сохранённый текст по глобальному сочетанию клавиш.

## Использование

1. Запустите `Kopiraiter.exe`.
2. Нажмите на поле «Сочетание клавиш» и наберите нужное сочетание.
3. Введите текст.
4. Нажмите «Сохранить и включить».
5. Перейдите в любое поле ввода и нажмите выбранное сочетание.

Настройки хранятся только на компьютере пользователя в `%LOCALAPPDATA%\Kopiraiter\settings.json`.

Приложение не использует буфер обмена: текст отправляется в активное окно через Windows `SendInput`. По правилам безопасности Windows обычное приложение не может вводить текст в окно, запущенное от имени администратора.

## Сборка готового EXE

Нужен [.NET 8 SDK](https://dotnet.microsoft.com/download/dotnet/8.0). В PowerShell выполните:

```powershell
.\build.ps1
```

Готовый автономный файл будет создан в `publish\win-x64\Kopiraiter.exe`. Устанавливать .NET на целевой компьютер не нужно.

GitHub Actions также собирает `Kopiraiter-win-x64` при каждом push в `main`; файл можно скачать из раздела **Actions → Build Windows app → Artifacts**.
