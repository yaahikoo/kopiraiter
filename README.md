# Копирайтер

Небольшое приложение для Windows, которое вводит заранее сохранённые тексты по глобальным сочетаниям клавиш.

## Использование

1. Запустите `Kopiraiter.exe`.
2. Нажмите на поле «Сочетание клавиш» и наберите нужное сочетание.
3. Введите текст и нажмите «Добавить комбинацию».
4. Убедитесь, что в нижнем списке у комбинации появился статус «Активна».
5. Добавьте другие сочетания при необходимости.
6. Перейдите в любое поле ввода и нажмите сохранённое сочетание.

Кнопка закрытия и сворачивание скрывают окно в системный трей — горячие клавиши продолжают работать. Чтобы полностью завершить программу, нажмите правой кнопкой мыши на значок в трее и выберите **Выход**.

Глобальные клавиши автоматически перерегистрируются, если Windows пересоздаёт нативное окно приложения.

Настройки сохраняются автоматически и хранятся только на компьютере пользователя в `%LOCALAPPDATA%\Kopiraiter\settings.json`. Настройки из версии 1.0 автоматически переносятся в новый список.

Приложение не использует буфер обмена: текст отправляется в активное окно через Windows `SendInput`. По правилам безопасности Windows обычное приложение не может вводить текст в окно, запущенное от имени администратора.

## Сборка готового EXE

Нужен [.NET 8 SDK](https://dotnet.microsoft.com/download/dotnet/8.0). В PowerShell выполните:

```powershell
.\build.ps1
```

Готовый автономный файл будет создан в `publish\win-x64\Kopiraiter.exe`. Устанавливать .NET на целевой компьютер не нужно.

GitHub Actions также собирает `Kopiraiter-win-x64` при каждом push в `main`; файл можно скачать из раздела **Actions → Build Windows app → Artifacts**.

На странице Releases публикуется готовый `Kopiraiter.exe` без дополнительного ZIP-архива.
